Two small apps for the Mac

One lives in your menu bar.
One rebuilds your desktop.

DepDeck keeps Homebrew, npm and cargo tools up to date from a menu bar popover. Desktop Shell swaps the Dock for a Windows XP-style taskbar and Start menu, and adds iOS-style folders and glassy widgets. Both are public on GitHub and built with SwiftUI. Below, you can use a drawing of each.

In-page recreations Everything below is drawn with HTML, CSS and JavaScript from the apps' source code. These are not screenshots and not the apps: the package names, files and songs are sample data, nothing is installed or run, and nothing leaves your browser.

DepDeck

A macOS menu bar app for managing command-line tools and dependencies across Homebrew, npm (global) and cargo. Click the box in the drawn menu bar to open it.

What it does

  • Menu bar badge: a box icon with the number of outdated packages, plus a warning count when anything is deprecated or disabled.
  • Installed: every tracked package with its version, a filter box and an uninstall button.
  • Updates: one-click upgrade per package, or Update All. Optional auto-upgrade on a schedule (Settings).
  • Issues: deprecated or disabled packages with the reason, a Replace with button when the package manager suggests a successor, and Uninstall.
  • Search: Homebrew formulae and crates.io, with install from the UI.

How the recreation differs

  • The packages, versions and deprecation reasons are made up. The real app reads brew info, npm ls -g and cargo install --list.
  • Updates here are timers. The real ones run brew upgrade, npm install -g or cargo install --force as you.
  • The demo switch can fail an update to show the red error banner the app uses.

Facts

  • macOS 14 or later, Swift package, built with swift build -c release.
  • No special macOS permissions. It runs your package managers through a login shell, and asks crates.io for cargo versions.
  • No accounts, analytics or telemetry.
  • No release builds yet: build it from source.

Desktop Shell

A Windows XP-style taskbar and Start menu, iOS-style desktop folders and widgets for macOS. Four small background services that share one settings domain. Open the Start menu, open a folder, change a setting, or run desktopctl in the terminal.

The four services

  • XP Taskbar: replaces the Dock, hidden in full-screen apps. Start (tap Option) opens an XP Start menu with pinned and frequent apps, All Programs, search (apps instantly, files via Spotlight), recent documents, your folders, Desktop Settings and Turn Off Computer. One button per open app, a Downloads window, a tray clock, and a window tiler.
  • Desktop Folders: every folder on your Desktop as an iOS-style folder, loose files grouped by type. Drag to rearrange, click to zoom open.
  • Desktop Widgets: an Aero panel with Now Playing, calendar, battery, CPU and memory, and storage, dockable to any edge.
  • Desktop Hotkeys: CmdCtrlT opens a Ghostty terminal; tap Option for Start.

How the recreation differs

  • Apps, files, folders, the song and the system numbers are sample data. Windows here are drawings that stand in for the real apps.
  • The tiling rule is the real one: widgets, folders and the taskbar reserve strips, and windows are kept in what is left (Keep Windows Clear). Switch on Show reserved strips to see them.
  • The terminal understands desktopctl status|stop|start|restart|disable|enable and acts on the drawn services only.
  • Power buttons do nothing here. On a Mac, macOS asks first.

Facts

  • macOS 14.4 or later, Swift package, installed with ./install.sh. Launched at login and restarted if it crashes, by launchd.
  • Permissions, each asked once: Accessibility (window tiler, taskbar and hotkeys), Downloads folder, Desktop folder, Automation for Music.
  • Nothing leaves your Mac except Now Playing's artwork lookups on Apple's public iTunes Search API and Apple Music pages (and YouTube's player, if you turn on its loop).
  • MIT licence. It started inside Himawari, the live music wallpaper, and works with or without it.

Build them yourself

Neither app has a packaged release yet, so both are built from source with the Swift toolchain (Xcode or the Command Line Tools).

DepDeck

git clone https://github.com/dhairyab0069/DepDeck
cd DepDeck
swift build -c release
.build/release/DepDeck &

github.com/dhairyab0069/DepDeck

Desktop Shell

git clone https://github.com/dhairyab0069/desktop-shell-mac
cd desktop-shell-mac
./install.sh
./desktopctl status
